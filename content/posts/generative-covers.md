画廊需要画。但我不想为每篇文章去找配图：图库照片有股廉价的香气，AI 插画又太吵。

所以这里的每一幅"画作"，都是浏览器现场画出来的。

## 种子与命运

每篇文章的 slug 会被散列成一个整数种子，喂给一个确定性的伪随机数生成器：

```ts
const rand = mulberry32(hash(slug));
```

从此这篇文章的封面就被命运决定了：构图、密度、留白、纹理，每次打开都分毫不差。这很重要——**封面是文章的脸，脸不能每天换。**

## 三种构图

封面只用墨与象牙两色，但有三种性格：

- **等高线**：几十条被分形噪声扰动的细线，像夜里的山脊；
- **颗粒辉光**：一团缓慢的光晕、一道地平线，附着浓重的胶片颗粒；
- **极简几何**：一个圆、一条垂线、一枚小小的实心圆点，仅此而已。

## 噪声的品味

分形噪声（fBm）是生成艺术的盐，少了乏味，多了发苦：

```ts
function fbm(x: number, y: number, octaves = 4) {
  let sum = 0, amp = 0.5, freq = 1;
  for (let i = 0; i < octaves; i++) {
    sum += amp * noise(x * freq, y * freq);
    amp *= 0.5;
    freq *= 2;
  }
  return sum;
}
```

四个倍频程足够了。再多，线条会开始发毛，安静就没有了。

最后压上一层细颗粒和暗角——不是为了做旧，是为了让纯数字的图案有一点"纸"的疲惫感。
