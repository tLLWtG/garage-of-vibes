# garage-of-vibes

A small collection of browser games and interactive experiments.

## Projects

| Project | Branch | Description | Stack |
| --- | --- | --- | --- |
| **Seed the Dungeon**<br/>明明只是种田，为什么会长出魔王城啊？ | [`seed-the-dungeon`](https://github.com/tLLWtG/garage-of-vibes/tree/seed-the-dungeon) | Plant a field by day, then explore what it turns into underground. | React · TypeScript · Vite · Zustand · Web Audio |

## Run

```bash
git clone https://github.com/tLLWtG/garage-of-vibes.git
cd garage-of-vibes
git switch <branch>
npm install
npm run dev
```

Replace `<branch>` with a branch name from the table. Each project branch has
its own README with screenshots, controls, and build notes.
