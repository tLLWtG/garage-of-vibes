**Seed the Dungeon**，一个跑在浏览器里的种田+肉鸽原型游戏。

白天，你在农田里摆放种子、浇水、规划路径；入夜后，同一块地会变成地牢。种下的格子成为房间，空着的格子成为墙。不同种子决定房间类型，成熟度同时影响收益和危险。探索结束后带回新的种子，再用它们设计下一轮地牢。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器（默认 http://localhost:5173）
npm run build      # 生产构建
```

这是一个纯前端项目，不需要后端服务。存档保存在 `localStorage`，刷新页面后会自动恢复。

## 玩法

1. 在农田中放下门种和其他种子，形成下一次地牢的布局。
2. 给种子浇水提高成熟度。成熟度越高，房间奖励越好，敌人也越强。
3. 入夜后下潜，农田会按照当前布局生成地牢。离入口越远的房间，奖励倍率越高。
4. 逐房探索地牢。战斗是轻量回合制，敌人意图公开，可以攻击、重击、格挡、喝药或撤退。
5. 带回精华和种子，扩建农田、升级道具，并为下一季准备新的组合。

## 系统

### 种子

| 种子 | 稀有度 | 长成 | 效果 |
| --- | --- | --- | --- |
| 门种 | — | 入口 | 每季免费一颗，必须种下，地牢唯一入口 |
| 铜芽 | 普通 | 铜芽巢室 | 基础战斗房，掉精华与普通种子 |
| 露根 | 普通 | 泉水房 | 治疗泉水；同时**灌溉四邻**（有效成熟度 +1） |
| 荆棘 | 普通 | 荆棘廊 | 穿行会受伤；提高相邻房间奖励（每丛 +40%） |
| 心藤 | 罕见 | 心藤龛 | 三选一祝福（力量 / 树皮 / 吸血……） |
| 火帽 | 罕见 | 火帽窟 | 高危战斗；相邻铜芽的敌人更强，掉落 ×1.75 |
| 雾铃 | 罕见 | 迷雾铃堂 | 随机事件房，从 5 组事件中出现二选一 |
| 微光 | 稀有 | 微光宝库 | 高奖励宝库；相邻战斗房会生成守卫（×1.6） |
| 王种 | 稀有 | 王座窟 | 根须霸主 Boss：固定行动循环，召唤芽虫 |
| **夜枯** | 诅咒 | 灾厄窟 | 启用灾厄威压（敌人生命 ×1.15、攻击 +1）；踏入会受重伤，但奖励更高 |
| **大地之心** | 传说 | 大地之心 | 两阶段终局 Boss，击败后通关 |
| 蒸露 | 杂交 | 蒸汽温泉 | 回满生命并攻击 +1（露根 × 火帽） |
| 铁棘 | 杂交 | 精英巢室 | 精英战斗房，奖励较高，可掉落王种（铜芽 × 荆棘） |
| 辉心 | 杂交 | 辉光圣龛 | 强化版三选一祝福（微光 × 心藤） |

特定种子相邻且双方有效成熟度满级时，会在下潜时结出杂交种子。种植界面会提前显示可触发的杂交组合。

### 天气

| 天气 | 效果 |
| --- | --- |
| 晴朗 | 基准，无修正（第 1 季固定） |
| 甘霖 | 开局水 +2（可超上限） |
| 旱光 | 开局水 −1，但所有房间精华 ×1.2 |
| 雾月 | 奖励倍率 +0.15，但敌人攻击 +1 |
| 寒潮 | 敌人生命 ×0.85，但泉水治疗 −4 |
| 丰收月 | 种子额外掉落概率 +25% |

每一季都有一条天气规则。天气会影响水量、奖励或敌人强度，并在下潜时写入本次地牢。

### 终局

达成「屠王者」和「初次杂交」后，商店会解锁终局种子「大地之心」。击败它后进入通关结算，并可以继续无尽游玩。

### 成长

精华可用于解锁地块、购买种子、升级水壶和药水袋，也可以建造一次性永久建筑。里程碑会提供阶段目标和一次性奖励。

## 实现

- 种植阶段会预览邻接、杂交、天气和诅咒带来的数值变化。
- 游戏界面使用 SVG 图标和 CSS 变量主题；音效由 Web Audio 实时合成。
- 核心规则集中在 `src/game`，UI 组件集中在 `src/components`。

## 技术栈

- Vite + React 19 + TypeScript（strict）
- zustand + immer（状态管理与 localStorage 持久化，含跨版本存档迁移）
- framer-motion（翻转入场 / 战斗反馈动画）

```
src/
  game/        纯逻辑（无 UI 依赖）：种子表、邻接效应、天气、地牢生成、
               战斗、掉落、事件、里程碑、音效合成、zustand store
  components/  视图：FarmView / DungeonView / CombatPanel / ResultView / HUD / icons
docs/          README 截图
```
